# Интернет-магазин металлопроката «Нержавеющая сталь и не только»

Современная e-commerce платформа для продажи металлопроката из различных сплавов. Проект включает удобную навигацию, расширенную систему фильтров (по материалу, категории, цене, наличию и скорости отгрузки) и полнофункциональную корзину.

## Технологический стек

Проект построен на современном стеке технологий для обеспечения высокой производительности, SEO-оптимизации и удобства поддержки:

- **Фреймворк:** Next.js 16 (App Router) + React 19 + TypeScript
- **База данных и ORM:** PostgreSQL + Prisma (с нативным адаптером @prisma/adapter-pg)
- **Стилизация:** Tailwind CSS v4
- **UI-компоненты:** Radix UI / компоненты в стиле shadcn/ui, class-variance-authority, clsx, tailwind-merge
- **Управление состоянием:** Zustand (для корзины и глобального стейта)
- **Иконки:** Lucide React
- **Дополнительно:**  axios (API-запросы)

## Возможности проекта
- Умный поиск и сортировка товаров (по популярности, новизне, наличию на складе).
- Многоуровневая фильтрация: по материалам (нержавеющая сталь, алюминий, медь и др.), категориям проката, ценовому диапазону и количеству.
- Интерактивная корзина с сохранением состояния между сессиями.
